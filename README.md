## TFD Translate To Fd
TFD is a simple library, can be used to develop cross platform library that need to handle unix fd and windows based SOCKET and HANDLE. 
It provides with function that can be used to get a relevent translation of Windows based HANDLE/SOCKET to unix style fd.

## SETUP
  - clone the repo:
     ```bash
       git clone https://github.com/Harshsharma-0/tfd.git

      ```

  - copy the header:
  - include in your code : 
       ```c++ 
             #include "tfd.hpp" 
       ```
